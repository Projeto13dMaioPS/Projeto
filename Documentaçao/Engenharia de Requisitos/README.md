## Documentação de Engenharia de Requisitos

A especificação e a modelagem de Engenharia de Requisitos do sistema estão centralizadas na pasta `/documentacao`.

**Nota Importante:** O **Diagrama de Casos de Uso** completo e a **descrição textual detalhada de cada caso de uso** (com seus respectivos fluxos principais, alternativos, exceções e notas) estão presentes e configurados diretamente dentro do arquivo do modelo:
**Arquivo:** `/documentacao/DiagramaCasodeUsoMuseuDigital.astah` (Abra utilizando a ferramenta Astah UML para visualizar a documentação completa).
